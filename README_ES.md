# Alex APK Builder 0.1.0 — base fuente

Esta es la aplicación Android original. En esta versión, la compilación de proyectos externos todavía se realiza localmente mediante Termux.

## Compilar esta aplicación en GitHub Actions
Abre Actions → Compilar Alex APK Builder → Run workflow. Descarga el artefacto AlexAPKBuilder-debug-apk al finalizar.

## Limitaciones
Esta base todavía no incluye importador ZIP, compilación remota desde la interfaz, integración Codemagic/Bitrise, editor visual de iconos ni consola de logs integrada. El workflow compila únicamente esta aplicación.

## Seguridad
No subir tokens, contraseñas, keystores ni claves privadas al repositorio público.
